# AugieLab

Small things Mark builds, mostly for fun. Live at [augielab.dev](https://augielab.dev).

Each project lives in its own folder (for example `/pomodoro`), and the home page is a server rack where every project is a rack unit.

Hosted on Cloudflare Pages: every push to `main` deploys automatically.
